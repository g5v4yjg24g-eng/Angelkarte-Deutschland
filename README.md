# Fangpunkt

Angel-App für ganz Deutschland als Progressive Web App: Gewässer finden, Angelstellen und Stege merken, Fänge dokumentieren und auswerten. Nicht kommerziell; persönliche Daten bleiben auf dem Gerät.

**Stand:** Meilenstein M1 (App-Hülle, Designsystem, Intro, PWA). Karte, Fangbuch und Statistik folgen in M2–M6.

## Schnellstart
```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm test       # Unit-Tests
pnpm e2e        # End-to-End-Tests gegen den Produktionsbuild
```
